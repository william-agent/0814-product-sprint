# 0814 Product Sprint

2026-08-14 主管 Hubert 交辦的兩個 AI 產品題目。兩題皆為「純執行」性質：不需要金融 domain know-how、不需要假設驗證，重點是**速度與可量產性**。

---

## 題目一：財經新聞自動化轉短影音（fin-news-shorts）

[查看題目一完整任務說明](./task1.md)

### 目標
把既有的財經即時新聞文章（開盤前推播、盤中快訊、美股大事等，目前皆為文字形式），**全自動**轉成短影音，做成像 Shorts / IG Reels 一樣往下滑的觀看體驗——「Reels 版的投資網誌」。

### 要求
- 第一階段聚焦「文章進 → 影片出」，先證明影片能生成、看得懂，而且不需要大量人工溝通。
- 探索 **3–4 種可量產的內容模板**，避免所有影片都採用相同的主播口播形式。
- 不把既有人工流程當成唯一答案；從原始文章與完成影片反推 **2–3 條 AI 生成路徑**。
- 比較各路徑的生成速度、穩定性、自動化程度、成品品質、人工介入量與單支成本。
- 長期目標為全流程自動化及可規模化產出；第一階段不包含自動發布、投放或外部熱門新聞抓取。

## 題目二：專業人士 AI 個人網站（ai-profile-site）

### 目標
給一份專業人士清單（首批：5 位醫生），**用 AI 全自動**幫每人生成個人形象網站。目標客群：醫生、律師、會計師、立委等有公眾形象需求者（傳統做個人網站要價數十萬）。

### 網站內容（參考市面醫生個人網頁）
- 衛教文章、看診地點、專業與證書、參加協會、看診時間
- 一鍵跳轉預約
- 進階：案例展示、代言、產品售賣、純形象頁
- **多種風格**可選（色系、版型、模塊勾選、模塊排序如門診/形象照區塊），避免每個人的網站長一樣

### 關鍵功能：用講的就能改（vibe-coding 後台）
- 用戶登入後台後，用**自然語言**提需求即可完成修改：「新增兩篇文章」「主頁照片換成最新形象照」「門診時間加註」「第二段和第三段對調」
- **不要做成傳統編輯器**（醫生沒時間點來點去改顏色）；體驗類似 ChatGPT：選一段 → 說要改什麼 → AI 重跑
- Chat 介面可上傳/拖曳圖片，直接指定用途（如換主圖）
- TA 是連 Claude Code、GitHub 都不會用的人，一切必須在網頁後台內完成

### 前置參考
- 之前同事（皮革）幫立委做過半套：輸入 Facebook/名字即自動生成網站，但「用戶自行修改」的部分沒做完 → **先找皮革拿既有成果參考**
- 參考案例：立委洪孟楷的網站（自行串接 YouTube 等大量資訊）；日本政治家幾乎人人有競選個人頁，台灣尚無人做
- 商業模式**現階段不用想**（壁壘低、可能免費化，重點是先做、持續優化；未來可能方向：站內售賣抽成、金流串接、廣告合作抽成）

## 共同原則

1. 兩題都不需要商業判斷，內容來源皆已確定 —— 直接執行
2. 速度優先：成本夠低、速度夠快本身就是競爭力
3. 一切以自動化、可量產為前提
4. 題目一先建 pipeline 骨架，等素材確認即可接上；題目二先收集既有成果與參考網站
