# TechNews Research

## 四支影片的簡短觀察

| 影片主張 | 敘事方法 |
|---|---|
| [CPO 量產真正的守門員是測試](https://www.instagram.com/technewsinside/reel/DcKOT4UGwOr/) | 先指出隱藏瓶頸，再解釋為什麼它阻礙量產 |
| [日本的技術優勢沒了？](https://www.instagram.com/technewsinside/reel/DcJauHjCZeQ/) | 舊優勢 → 評分規則改變 → 原有領先可能失效 |
| [機器手的關鍵戰場](https://www.instagram.com/technewsinside/reel/DcJGOYUjmZm/) | 工程限制 → 業界共同解法 → 案例 → 解法代價 |
| [EMIB-T 把電力直灌晶片](https://www.instagram.com/technewsinside/reel/DcHphPdk5jw/) | 舊方法的問題 → 新機制如何運作 → 帶來什麼好處 |

這四支影片不是把文章平均濃縮，而是先選出一條因果線。

例如「機器手」影片的核心不是列出特斯拉、NASA、Shadow Robot 和 1X 各自使用的技術，而是：

> 因為手掌空間有限，所以馬達被移到前臂；纜線解決空間問題，卻帶來鬆弛與磨損。

其他公司案例用來支撐這條主線。
